Datos que recopilamos

No recopilamos datos personales de las personas que ven nuestro contenido. No existen formularios de registro, cuentas de usuario ni sistemas de suscripción gestionados por nosotros más allá de las funciones nativas de cada plataforma (seguir, suscribirse, etc.), que se rigen por la política de privacidad de esa plataforma.

Uso de APIs de terceros

Usamos la API de TikTok exclusivamente para publicar contenido de forma automatizada en nuestra propia cuenta (@rebuscandochollos). No accedemos ni gestionamos cuentas de terceros.
